# Todo App

A simple todo app built with HTML, CSS and JavaScript. Tasks are saved in the browser, so they stay after you refresh the page.

## Features

- Add a task
- Mark a task as done
- Delete a task
- Filter tasks: All, Pending, Done
- Delete all completed tasks at once
- Saved automatically with localStorage

## Tech used

- HTML5
- CSS3
- JavaScript (no libraries or frameworks)

## How to run

1. Download or clone this repository
2. Open `index.html` in any browser

No installation needed.

```bash
git clone https://github.com/USERNAME/todo-app.git
cd todo-app
```
